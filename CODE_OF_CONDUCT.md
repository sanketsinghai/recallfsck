# Code of conduct

Treat contributors with respect. Technical disagreement is welcome; harassment,
threats, discrimination, doxxing and repeated unwanted contact are not.
Keep discussion focused on evidence and the project. Respect personal boundaries
and avoid sharing private information or credentials.

Maintainers may edit or remove harmful content and restrict participation, using
proportionate action and considering context. Report concerns privately to the
repository owner. A public contact address must be established before launch;
do not post sensitive reports publicly while that channel is being set up.
