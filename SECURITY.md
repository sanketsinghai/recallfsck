# Security

Report vulnerabilities privately through
https://github.com/sanketsinghai/recallfsck/security/advisories/new .
Private vulnerability reporting is enabled. Do not disclose credentials, customer
source documents or exploit details in public issues.

This release candidate supports disposable synthetic tests. Never run mutating
experiments against production servers or real customer data. Reports contain
synthetic document text and operation histories. Application adapters must avoid
persisting credentials and private source content in evidence.

The latest release candidate is the supported version during initial development.
Security reports are reviewed by the repository owner; no response-time service
level is promised.
